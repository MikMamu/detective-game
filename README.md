# 主机城 ·《谁动了我的0和1？》d

面向**中职计算机专业学生**的计算机知识推理游戏：把 CPU、内存、硬盘、操作系统、编译器、网络协议、缓存变成七个"嫌疑人"，
学生扮演系统调查员，在破案过程中学会计算机组成与工作原理。

核心机制是**费曼学习法**：想拿到线索，必须先把知识卡**用自己的话 + 生活类比讲清楚**——
AI 费曼判官会指出你漏了什么、类比哪里不对，讲明白才给"费曼点"，费曼点才能兑换线索。

## 快速开始

```powershell
# 学生：启动网页版，浏览器打开 http://127.0.0.1:3123
node src/cli.js serve --port 3123

# 老师：生成可打印桌游包（角色卡 / 线索卡 / DM 手册 / 投票卡）
node src/cli.js pack --out pack-zero-one.html

# 老师备课：单独测试费曼判官对某段讲解的评分
node src/cli.js judge --concept kc_cache --text "缓存就像贴在桌边的便利贴……"

# 配置 DeepSeek API Key（配置后 AI 判官与角色扮演全部启用；不配置也能玩，走规则判分）
node src/cli.js setkey --key sk-你的key
```

> 本机 PowerShell 禁跑 .ps1 时，用 `node src/cli.js xxx` 直接调用即可（无需 npm install，零依赖，Node ≥ 18）。

## 一局怎么玩（网页版）

开局会**随机发给你一张身份卡**——你就是七个部件中的一个（CPU 芯芯 / 内存小存 / 硬盘阿硬 / 操作系统欧思 / 编译器康派 / 网络协议提希 / 缓存卡西）。
你有自己的**秘密**、**目标**和**处境**：秘密可能让你被冤枉，所以你不能只顾破案，还得把自己讲清楚。

1. **问话**：点左侧其他六位居民，问出事发凌晨 2:00–3:01 的线索；问对关键点，他们才会说出秘密。
2. **费曼讲解**：点「🎓 费曼讲解」，选一张知识卡，用大白话 + 生活比方讲给"完全不懂电脑的人"听。
   AI 判官给 0–3 分并写具体反馈（漏了哪点、类比是否贴切、追问一个问题）——**分数就是费曼点**。
   讲清**你自己**的知识卡额外 +1 点（你是本人，讲不明白最说不过去）。
3. **兑换线索**：用费曼点解锁私人线索（编译日志、权限记录、反编译比对报告……）。
4. **出示线索**：把线索当面出示给当事人，他才会承认某些秘密（例如拿着编译日志去问编译器康派）。
5. **还原时间线**：把被打乱的 7 条日志事件按发生顺序排好，并指认每步的主要责任环节
   （顺序 60 分 + 归因 40 分，80 分合格，可反复重排）——**结案前必须完成**，提交后会揭晓正确时间线与"最关键的一环"。
6. **投票结案**：从四个选项里选出"谁在源码里植入了后门"。
7. **真相复盘**：真实时间线、**系统性原因**、数据流图、你的费曼成绩单、**你的结局**（最佳调查员 / 合格 / 替罪羊 / 结案失败），以及课后追问。

> 游戏内**不需要写任何文字**：产出物是"排好的时间线"，判分完全确定、即时反馈、零 AI 成本。
> 想额外练写作的老师，可用 `node src/cli.js grade --file 学生报告.txt` 批改手写的《事故分析报告》（课外作业，范文见 `docs/incident-report-model.md`）。

### 身份与结局

| 你抽到的身份 | 你的处境 |
|---|---|
| CPU 芯芯 | 你执行了那条可疑指令，得证明"执行者 ≠ 决策者" |
| 内存 小存 | 内存泄漏是你的失职，别让它变成"泄密帮凶" |
| 硬盘 阿硬 | 日志缺失容易被当成销毁证据，你得说清"没落盘 ≠ 弄丢了" |
| 操作系统 欧思 | 权限是你发的，你得讲清"点同意 = 交出通行证" |
| **编译器 康派** | **你就是内鬼**——把怀疑引向别人，别被反编译报告锁死 |
| 网络协议 提希 | 你没坚持 HTTPS，得证明自己只是"邮差" |
| 缓存 卡西 | 旧密钥是你递出去的，你得讲清"快"和"准"的取舍 |

结局由三件事决定：投票是否正确、你有没有讲清自己的知识卡、事故报告是否合格。

## 教学设计要点

| 机制 | 教学作用 |
|---|---|
| 知识卡（7 张） | 指令周期 / 内存与内存泄漏 / 持久化存储 / 进程与权限 / 编译与解释 / 三次握手与 HTTPS / 缓存一致性 |
| 费曼判官 | 逼学生"讲出来"：只背术语最多 1 分，必须讲清"是什么、为什么、不用会怎样"+ 类比 |
| 费曼点兑换线索 | 把"讲明白"变成游戏里的硬通货，讲解质量直接决定破案进度 |
| 角色会纠正你 | 计算机部件由 AI 扮演，你在对话里讲错了，它会当场纠正并用自己的类比重讲 |
| 系统性事故复盘 | 直接元凶是编译器，但事故由"后门 + 权限过宽 + 缓存失效 + 内存泄漏 + 明文传输 + 写入延迟"共同造成 |

**真相**：编译器康派（他发现了后门函数却不上报，还在优化阶段插入了 `if(debug) send_key();`）。
复盘强调：任何一环被拦住，事故都不会发生——这是工程上的"瑞士奶酪模型"。

## 目录结构

| 文件 | 职责 |
|---|---|
| `cases/zero-one.json` | 旗舰案件：7 部件 / 知识卡 / 13 条线索 / 真相与复盘（教学内容全在这里） |
| `src/feynman.js` | **费曼判官**：AI 逐点评分 + 反馈 + 追问；无 Key 时降级为关键词规则判分 |
| `src/incident.js` | 案件运行时：抽身份 / 提问 / 出示线索 / 讲解 / 兑换 / **时间线判分** / 投票 / 复盘 |
| `src/report.js` | 可选的《事故分析报告》评分子模块（仅用于课外写作作业的 `grade` 命令） |
| `src/prompt-factory.js` | 提示词工厂：部件角色扮演（含"讲错要纠正"）与费曼判官两套提示词 |
| `src/server.js` | HTTP 服务与 REST API（秘密与真相只存在服务端，永不下发前端） |
| `src/pack.js` | 桌游包渲染（可打印 HTML：角色卡 / 线索卡 / DM 手册 / 投票卡） |
| `src/cli.js` | 命令入口：serve / pack / judge / setkey |
| `web/*` | 网页前端（零依赖 vanilla JS，浅色课堂风，适合投影） |
| `cases/legacy/`、`src/final-judge.js` 等 | 旧版"谋杀推理 + 案件生成"模块，保留但未接入教学版 |

## 扩展新案件

在 `cases/` 下新增一个 `type: "incident"` 的 JSON（照 `zero-one.json` 的结构），重启服务即出现在列表里。
老师按方案里的建议替换知识模块即可升级难度：

- 把「缓存」换成「数据库事务」，把「网络协议」换成「加密算法」；
- 改 `cast[].knowledge_card` 的要点与类比、`clues` 的线索、`truth` 的真相与复盘。

### 关于投票选项（为什么是 4 个而不是 7 个）

案件的 `vote_options` 字段决定可指认对象，当前为 4 人（CPU 芯芯 / 编译器康派 / 网络协议提希 / 操作系统欧思）。
理由是本题问"**谁在源码里植入了后门**"——只有能接触「源码 → 编译 → 运行 → 通信」链路的部件才有这个能力；
内存、硬盘、缓存的故障属于**系统性原因**，会在复盘里逐条说明（这正是要教的重点：事故往往是多个环节凑成的）。

想改成 7 人全可投，只要在 `vote_options` 里补上 `ram`、`disk`、`cache` 即可；网页投票弹窗会自动列出未在选项中的角色并解释原因。

## API（网页版使用）

```
GET  /api/cases                 案件列表
GET  /api/cases/featured        默认案件（含公开的知识卡；秘密与真相不下发）
POST /api/sessions              开局 {case_id} → session_id + 初始状态
POST /api/sessions/:id/ask      问话 {component_id, text}
POST /api/sessions/:id/present  出示线索 {component_id, clue_id}
POST /api/sessions/:id/explain  费曼讲解 {concept_id, text} → 评分+反馈
POST /api/sessions/:id/unlock   兑换线索 {clue_id}
POST /api/sessions/:id/timeline 还原时间线 {placements:[{event_id, order, actor}]} → 顺序分+归因分
POST /api/sessions/:id/vote     投票 {component_id} → 复盘数据
GET  /api/sessions/:id/state    当前状态（费曼点/线索/进度）
```

> 成本参考：一次讲解评判约 ¥0.003–0.01（deepseek-reasoner 只在判分时调用一次），
> 一节课 40 人各讲 3 次约 ¥0.5–1。价格以[官方定价页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)为准。
